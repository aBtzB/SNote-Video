Repository name: **SNote-Video**

## About
Local video subtitle generation and translation, with downloadable models, editable cue timing, bilingual preview, and SRT/VTT exports.

## Topics
python, javascript, subtitles, video, whisper, faster-whisper, translation, ffmpeg, offline, sqlite

## Description
SNote Video turns dialogue in a video into subtitles that can be reviewed and translated locally. Users choose their models, add a clip, then check the wording and timing while watching a preview. The editor supports individual cue times, a global subtitle offset, bilingual playback, and subtitle export.

The application combines Python, SQLite, FFmpeg, and plain JavaScript with faster-whisper and local Argos translation models. It runs on a computer through a localhost browser interface.
