YOUR LOCAL TOOLKIT

Choose what you need.

Download a speech model and any translation pairs you want. Nothing downloads until you choose it. Once installed, models work offline.

FFmpeg is needed for video

Install FFmpeg with FFprobe and add its bin folder to PATH. Restart this app afterwards. See README.md for Windows, macOS, and Linux instructions.

Install the speech dependencies first

Run this from the project folder using the same Python environment, then restart SNote Video.

python -m pip install -r requirements.txt

Tiny is the lightest option (about 78 MB). Larger models use more disk space and memory, and may run slowly on a CPU. Download size is shown during transfer.

Language pairs are directional. English → Spanish and Spanish → English are separate downloads. The list comes from the official Argos index and shows languages this notebook supports. Packs are checked for compatibility during installation.

You can close this panel while downloading. Keep the SNote Video terminal running. Installed models are available immediately.
